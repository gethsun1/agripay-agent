# Seven-slide pitch deck

## 1. Autonomous intelligence, paid one insight at a time

Core message: AgriPay Agent gives software agents a safe, inspectable way to buy granular
intelligence.

- One question becomes autonomous pay-per-use procurement.
- Genuine HTTP 402 and native HBAR settlement.
- Every purchase produces public proof.

Visual: question-to-receipt product hero. Speaker note: open with the Nandi maize question.
Evidence: production app plus three public Hedera transactions.

## 2. Agents cannot safely buy granular intelligence

Core message: subscriptions, API keys, and checkout flows do not fit autonomous, one-off purchases.

- Agents need resources dynamically, not as fixed bundles.
- An LLM must not control a wallet.
- Buyers need exact cost, delivery, and auditability.

Visual: broken subscription funnel versus one HTTP request. Speaker note: distinguish discovery
from payment authority. Evidence: exact three-resource preflight.

## 3. Autonomous pay-per-insight

Core message: the agent selects only what the question needs and pays only after deterministic
approval.

- Groq creates a schema-validated resource plan.
- Immutable registry and policy authorize spending.
- Delivered data alone enters final synthesis.

Visual: three provider cards flowing into one brief. Speaker note: current agricultural responses
are curated demonstration fixtures, ready to be replaced by real providers. Evidence: 0.07 + 0.05

- 0.04 = 0.16 HBAR.

## 4. x402 + Hedera

Core message: payment is an ordinary, machine-readable HTTP lifecycle.

- Request → 402 requirements → verify/settle → proof retry → 200.
- Native HBAR on Hedera testnet; exact integer tinybar accounting.
- Separate buyer, seller, and facilitator roles.

Visual: protocol sequence diagram. Speaker note: emphasize settlement before delivery and
facilitator-paid network fee. Evidence: transaction transfer and fee records.

## 5. Live proof

Core message: three autonomous purchases are independently verifiable.

- Three genuine 402 responses and three HTTP 200 deliveries.
- Three separate testnet settlements.
- HashScan, mirror-node, durable receipt, and sanitized developer views.

Visual: three receipt rows with QR codes to HashScan. Speaker note: open one transaction and show
transfers. Evidence: links in `docs/hashscan-evidence.md`.

## 6. Safety is the differentiation

Core message: the model plans; deterministic systems control money.

- Testnet-only, exact recipient/asset/amount, kill switch, and operator gate.
- Durable budgets, idempotency, replay prevention, backup, and reconciliation.
- Unsafe and over-budget purchases fail before signing.
- The same rail can serve agriculture, data, compute, and agent services.

Visual: Groq outside a policy-controlled wallet boundary. Speaker note: no claim that fixture data
is production agronomic advice. Evidence: security tests and public policy endpoint.

## 7. From demonstration providers to an open agent market

Core message: AgriPay Agent is a reusable payment and safety layer for real data-provider
integrations.

- Next: live agronomic and market providers with provenance and SLAs.
- Provider onboarding, tokenized price discovery, and richer policy delegation.
- Production Hedera readiness only after audit; mainnet is deliberately refused today.

Visual: provider ecosystem around the x402 rail. Speaker note: close on inspectable autonomous
commerce, not a single agriculture app. Evidence: modular resource/facilitator architecture.
